# Улучшения

## Защита данных
1. Обфускация для проведения платежей, в случае если на стороне клиники будет реализован свой сервис по оплате платежей
2. Скремблирование символов - для данных о пациенте/мед результатах анализа
3. Использование статической маскировки - перед деплоем новых версий компонентов в продакшен.

## Инфраструктурные
1. Реализация ролевой модели
2. использование шифрование траффика
3. защита от DDOS
4. сегмент TLS
5. сегмент WAF

## Тегирование
1. ФИО, дата рождения - PI (Personal Information)
2. Телефон, эл. почта - ADI (Additional Information)
3. место учебы, прописка - EI (Extended Information)
4. Хронические заболевания, проведенные операции,результаты анализов - MI (Medical Information)
5. Финансовые операции(проведние платежей, расчет зп и др) - FO (Financial Operations)
6. Операции ТМЦ - WO (Warehouse Operations)
