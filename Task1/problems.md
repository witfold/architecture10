# Проблемы
1. Т.к. все данные хранятся в excel файлах, то вероятность утечки с каждого "потребителя" крайне высока.
Ведь часто делаются локальные копии на потребительских ПК.
2. Обфускация данных не используется, данные хранятся as-is
3. Не все персональные данные предназначены для всех сотрудников компании, отсутствуют разграничение данных (ролевая модель)
4. Отсутствие аудита действий, совершаемых пользователями
5. Несоответствие 152 ФЗ
6. AD должна использоваться как единая точка аутентификации\авторизации для всех внутренних пользователей
